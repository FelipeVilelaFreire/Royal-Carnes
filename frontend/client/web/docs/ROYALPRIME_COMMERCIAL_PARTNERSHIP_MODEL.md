# RoyalPrime Commercial Partnership Model

Este documento registra uma proposta inicial de modelo comercial para o RoyalPrime considerando que o projeto pode evoluir como uma parceria, e nao apenas como uma venda tradicional de desenvolvimento.

O contexto e importante: este pode ser o primeiro projeto real com uma empresa, o cliente validou bem o MVP e demonstrou interesse em seguir. Ao mesmo tempo, o projeto ainda precisa virar sistema operacional de verdade: backend, admin, pedidos, assinatura, delivery, estoque e pagamentos. Por isso, a proposta precisa equilibrar entrada acessivel, mensalidade minima e possibilidade de upside.

## Decisao comercial principal

Nao tratar o RoyalPrime como um projeto fechado barato.

Tambem nao entrar como socio tecnico sem dinheiro mensal.

Modelo recomendado:

```text
Entrada inicial reduzida
  + mensalidade obrigatoria
  + escopo por fases
  + participacao pequena opcional
  + funcionalidades grandes como fases separadas
```

Esse modelo protege os dois lados:

- o cliente nao precisa pagar o valor cheio de uma software house logo no inicio;
- a equipe tecnica nao vira mao de obra infinita por uma promessa futura;
- o produto consegue evoluir com previsibilidade;
- a parceria tem upside se o canal online gerar receita.

## Entrada inicial

Nome sugerido:

```text
Kickoff tecnico + fundacao MVP
```

Faixa recomendada:

```text
R$ 10.000 a R$ 15.000
```

O que essa entrada cobre:

- organizacao tecnica;
- refinamento do roadmap;
- modelagem inicial;
- backend foundation inicial;
- estrutura do projeto;
- primeiras entidades;
- primeiras rotas;
- planejamento operacional;
- preparacao para sair dos mocks.

Importante:

```text
R$ 10.000 nao compra o sistema inteiro.
R$ 10.000 compra o inicio organizado da fundacao.
```

## Mensalidade minima

A mensalidade e a parte mais importante para nao transformar a parceria em trabalho infinito.

Planos possiveis:

| Plano | Valor sugerido | Inclui |
| --- | ---: | --- |
| Corretivo | R$ 2.500/mes | Bugs, ajustes pequenos e suporte leve |
| Evolutivo leve | R$ 5.000/mes | Corretivo + pequenas melhorias mensais |
| Evolutivo ativo | R$ 8.000 a R$ 12.000/mes | Desenvolvimento continuo, backend, novas telas, admin e evolucao do produto |

Recomendacao para este caso:

```text
R$ 10.000 de entrada
+ R$ 5.000/mes por 3 meses
```

Esse e um bom ponto de partida porque:

- nao assusta como um projeto de R$ 100k fechado;
- cria compromisso real do cliente;
- da folego minimo para evoluir;
- permite validar a operacao antes de prometer gateway, estoque avancado e logistica.

## Modelo parceiro com participacao

Se a conversa for de sociedade/parceria, a participacao deve ser pequena, documentada e condicionada.

Opcao 1: revenue share

```text
R$ 10.000 de entrada
+ R$ 3.500 a R$ 5.000/mes
+ 5% a 8% do faturamento liquido dos pedidos online
```

Periodo sugerido:

```text
12 a 24 meses
```

Vantagem:

- mais simples que sociedade formal;
- alinha incentivo com venda online;
- evita briga societaria cedo demais;
- permite testar se o canal digital realmente gera receita.

Opcao 2: participacao no produto digital

```text
R$ 10.000 de entrada
+ R$ 5.000/mes por 6 meses
+ 5% a 10% de participacao no produto digital
```

Condicoes recomendadas:

- contrato escrito;
- vesting ou consolidacao por entregas;
- responsabilidades comerciais do cliente claras;
- responsabilidades tecnicas da equipe claras;
- saida definida se alguma parte parar de executar.

Observacao:

```text
Para o inicio, revenue share e mais simples do que sociedade formal.
```

## Proposta recomendada

### RoyalPrime Parceiro MVP

Entrada:

```text
R$ 10.000
```

Mensalidade:

```text
R$ 5.000/mes por 3 meses
```

Inclui:

- backend base;
- clientes;
- enderecos;
- produtos;
- pedidos;
- admin operacional inicial;
- acompanhamento do cliente;
- assinatura e ciclo simples;
- correcao de bugs;
- pequenas melhorias evolutivas;
- organizacao dos mocks em contratos/API;
- preparacao para deploy e operacao.

Nao inclui automaticamente:

- gateway real;
- estoque avancado;
- roteirizacao;
- app do entregador;
- ERP;
- nota fiscal;
- integracao contabil;
- automacao completa de recorrencia;
- suporte ilimitado.

Depois dos 3 meses:

```text
Renovar por R$ 5.000 a R$ 8.000/mes
ou abrir nova fase maior com estoque, gateway e delivery mais completo.
```

Participacao opcional:

```text
5% do faturamento liquido dos pedidos online por 12 a 24 meses
```

ou:

```text
5% a 10% de participacao no produto digital, condicionada a contrato e execucao.
```

## O que nao fazer

Evitar:

- desenvolver tudo por R$ 10.000 e depois ver;
- sociedade verbal;
- percentual sem mensalidade;
- manutencao infinita inclusa;
- aceitar urgencia toda semana sem limite;
- colocar gateway, estoque, delivery, admin e assinatura avancada no mesmo pacote inicial;
- deixar o cliente acreditar que entrada inicial cobre todas as fases;
- aceitar escopo aberto sem priorizacao.

## Como explicar ao cliente

Texto sugerido:

```text
Como estamos entrando como parceiros e nao apenas como fornecedores, conseguimos reduzir o valor inicial do desenvolvimento. Mas para o projeto andar com qualidade, precisa existir uma mensalidade minima de evolucao e manutencao.

A entrada cobre a fundacao tecnica e o inicio organizado do MVP operacional. A mensalidade garante continuidade, correcoes e novas etapas. Funcionalidades maiores, como gateway de pagamento, estoque avancado e logistica mais completa, entram em fases separadas.
```

## Posicionamento recomendado

Para este primeiro projeto com empresa, a melhor posicao e:

```text
R$ 10.000 inicial
+ R$ 5.000/mes
+ participacao pequena condicionada
```

Por que:

- e acessivel para o cliente;
- valida comprometimento real;
- nao desvaloriza o trabalho tecnico;
- cria recorrencia;
- deixa espaco para upside;
- evita tentar vender um pacote grande demais cedo;
- protege a equipe de virar suporte infinito.

## Regra de manutencao

Separar manutencao em dois tipos:

### Corretiva

Inclui:

- bug;
- erro de tela;
- ajuste pequeno;
- comportamento quebrado;
- suporte leve.

Nao inclui:

- nova funcionalidade;
- nova regra de negocio;
- nova integracao;
- redesenho de fluxo.

### Evolutiva

Inclui:

- novas telas;
- novos endpoints;
- novos fluxos;
- melhorias de admin;
- estoque;
- pagamento;
- delivery;
- relatorios;
- automacoes.

Regra:

```text
Corretiva mantem o sistema funcionando.
Evolutiva aumenta o produto.
```

## Resumo executivo

O melhor modelo para este momento e uma parceria paga:

```text
Entrada inicial: R$ 10.000
Mensalidade minima: R$ 5.000/mes
Periodo inicial: 3 meses
Participacao opcional: 5% a 8% do faturamento liquido online
```

Isso posiciona a equipe como parceira, mas evita assumir todo o risco tecnico sozinha.
