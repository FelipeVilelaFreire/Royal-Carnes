# Client Hooks

Hooks reutilizaveis entre cliente web e cliente mobile.

Exemplos futuros:

- `useProducts`
- `useMyOrders`
- `useCustomer`
- `useAddresses`
- `useSubscriptionCycle`
- `useSubscription`

Regra:

```text
hook organiza loading, erro, estado de fluxo e chama api client
screen apenas renderiza e dispara acao
```
