# Admin Hooks

Hooks reutilizaveis dentro do Admin.

Exemplos futuros:

- `useAdminOrders`
- `useAdminProducts`
- `useAdminCustomers`
- `useAdminDeliveries`

Regra:

```text
hook organiza loading, erro, filtros, comandos e chama api client
screen admin apenas renderiza tabela, modal, detalhe e botoes
```
